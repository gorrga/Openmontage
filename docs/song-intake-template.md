# 🎬 Song Video Intake Template

Fill this in per song and send it (with the MP3 attached). This is everything
needed to produce a Jack-Hartmann-style alphabet/action lyric video + matching
YouTube thumbnail.

---

```
🎬 NEW ALPHABET-STYLE SONG VIDEO

1. SONG FILE: [attach the MP3 here]

2. TITLE (shown on screen + on the thumbnail):
   e.g. "B Is for Brave!"

3. LYRICS — paste the Suno block exactly, KEEP the section tags
   ([Intro] / [Verse 1] / [Chorus] / [Outro]):

   [Intro - spoken]
   ...
   [Verse 1]
   ...
   [Chorus]
   ...

4. THUMBNAIL:
   - Big text (≤ 3 words): e.g. "B is for BRAVE!"
   - Hero letter (the giant smiling character): e.g. B

5. SYNC ANCHORS (recommended — 5 timestamps for tight lyric sync):
   Open the MP3 in any player, note when each section STARTS (mm:ss),
   and fill these in. ~5 anchors is enough; I interpolate the rest.

   0:__   [Verse 1] first line ...
   0:__   [Chorus]
   1:__   [Verse 2] first line ...
   1:__   [Chorus]
   1:__   [Outro]

6. OPTIONS — delete any line to accept the default:
   - Aspect: 16:9 horizontal (default) | 9:16 vertical (Shorts/TikTok)
   - Colors/vibe: bright primary (default) | pastel | candy | <describe>
```

---

## Notes

- **Section tags do the heavy lifting.** Choruses are styled bigger/yellow with
  extra confetti automatically; lines are timed to the track length.
- **Sync anchors (field 5) are the quality lever.** I can't hear the audio, so
  without anchors I estimate timing from the song's energy (good, not perfect).
  With ~5 anchors I snap each section into place. If you skip them, just review
  the draft and tell me what drifts (e.g. "chorus 1 is ~2s late") and I re-render.
- **Batching:** want several at once? Repeat blocks 1–5 per song.
